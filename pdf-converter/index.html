이미지 여러 장을 한 개의 PDF로 합쳐요. 파일은 내 기기 안에서만 처리돼요.

사용 방법

합칠 이미지를 모두 선택하면 목록이 나타나요. 위아래 버튼으로 순서를 바꾸고, 필요 없는 파일은 삭제한 뒤 PDF로 저장하면 돼요. 목록 순서대로 한 페이지씩 들어갑니다.

페이지 크기 고르기

A4는 서류 제출이나 인쇄에 알맞아요. 이미지가 페이지 안에 비율을 지키며 가운데로 들어가요. 이미지 크기에 맞추기는 화면용 문서처럼 여백 없이 이미지를 그대로 페이지로 만들 때 써요.

이럴 때 쓰세요

계약서나 영수증, 증빙 서류를 사진으로 찍어 한 파일로 제출해야 할 때 좋아요. 사진이 어둡거나 얼룩이 있으면 스캔 변환으로 먼저 정리한 뒤 PDF로 합치면 더 깔끔해요.

알아두세요

이 도구는 이미지를 PDF로 만드는 기능만 지원해요. PDF를 이미지로 바꾸거나 PDF 파일끼리 합치는 기능은 아직 없어요. 이미지는 PDF에 JPG로 저장돼 투명 배경은 흰색이 되고, 아주 큰 사진은 인쇄 품질을 유지하는 선에서 크기가 줄어들어요. 신분증처럼 민감한 문서는 서버로 전송되지 않지만, 공용 기기에서 쓴 뒤에는 저장한 파일을 지워 주세요.

사용 방법

이미지를 여러 장 고르고, 순서를 정한 뒤 PDF로 저장하세요. 선택한 순서대로 한 페이지씩 들어가요.
