이미지 변환

이미지 형식을 PNG, JPG, WEBP로 바꾸고 크기와 용량을 줄여요. 사진은 내 기기 안에서만 처리돼요.

사용 방법

이미지를 한 장 또는 여러 장 선택하세요. 바꿀 형식과 화질, 크기를 고르면 아래에 변환된 파일 목록과 용량이 나타나고, 파일마다 저장 버튼을 눌러 내려받을 수 있어요.

어떤 형식을 고를까요

JPG는 사진에 알맞고 용량이 작아요. PNG는 글자나 로고처럼 선이 또렷한 이미지에 좋고 투명한 배경을 지킬 수 있어요. WEBP는 같은 화질에서 용량이 더 작지만 오래된 프로그램에서는 열리지 않을 수 있어요.

용량 줄이는 요령

이메일이나 지원서 사이트에 올릴 때 용량 제한에 걸리면 JPG로 바꾸고 화질을 70~85로 낮추거나 가로 크기를 줄여 보세요. 눈으로 보기엔 차이가 크지 않으면서 용량은 크게 줄어드는 경우가 많아요.

알아두세요

투명 배경 이미지를 JPG로 바꾸면 투명한 부분이 흰색으로 채워져요. 사진 속 위치 정보 같은 부가 정보는 변환하면 사라져요. WEBP를 지원하지 않는 기기에서는 PNG로 저장될 수 있고, 이때는 저장되는 파일 형식이 목록에 표시돼요.

사용 방법

이미지 선택, 형식 선택, 필요하면 가로 크기 줄이기, 저장 순서예요.
